## 2-3. 보유·파기 정책

| 데이터 | 보유 기간 | 비고 |
|---|---|---|
| 회원 정보 | 탈퇴 즉시 vs **분쟁 대비 30일** | 결정 필요 ⓒ |
| **인증 서류** | 검토 완료 후 **30일 자동 파기** | 사본·썸네일·임시파일 일체 포함 |
| 검토자 접근 로그(AccessLog) | **1년** | 법정 접속기록 보관 |
| 결제·거래 기록 | **5년** | 전자상거래법 |
| 매칭·대화 로그 | 매칭 종료 후 **6개월** | 결정 필요 ⓓ |
| 본인인증 CI/DI | 탈퇴 시 파기(중복가입 방지 목적 보존 시 별도 근거 필요) | 결정 필요 ⓔ |

> **결정 필요 ⓒ** 탈퇴 즉시 파기 vs 30일 보관 → **30일 보관(분쟁·악용 재가입 방지) 후 자동 파기** 권장. 단 인증 서류는 탈퇴 즉시 파기.
> **결정 필요 ⓓ** 대화 로그 보존: 분쟁·신고 대응 위해 **종료 후 6개월** 권장, 신고 진행 건은 처리 종료까지 연장.

**자동 파기 cron 명세 (Phase 3 구현)**
- 모듈: `packages/db` + 스케줄러(예: Vercel Cron / 별도 워커).
- 주기: 매일 03:00 KST.
- 작업: ① 검토완료+30일 경과 인증 서류 S3 객체 삭제 + DB 메타 `deleted_at` 기록 ② 탈퇴+30일 경과 회원 하드 삭제 ③ 매칭종료+6개월 대화 삭제 ④ 1년 경과 AccessLog 아카이브.
- **백업본 파기**: 백업 보존 = 본 데이터 파기 시점 + **최대 35일**(백업 롤링 주기). 백업에서 개별 삭제 불가 시, 백업 만료로 자연 소멸하되 복원 시 재파기 트리거.

## 2-4. 안전성 확보조치 (개인정보보호법 시행령 §30) — 8개 조치 구현안

1. **내부관리계획 수립** — 개인정보 보호책임자(CPO) 지정, 연 1회 계획 수립·교육. (결정 필요 ⓕ: CPO 지정자)
2. **접근권한 관리** — 운영자 viewer/reviewer/admin 3단계(verification-sop §5-1), **분기별 권한 리뷰**, 퇴사 즉시 회수.
3. **접근통제** — 어드민 콘솔 **IP 화이트리스트 + MFA**, 세션 타임아웃, 비정상 접근 알림.
4. **개인정보 암호화**
   - 인증 서류: **S3 SSE + KMS**, 사용자별 **envelope encryption** 검토.
   - DB 민감 필드(CI/DI, 휴대폰): **AES-256 컬럼 암호화**.
   - 패스워드(소셜 미사용 시): **argon2id** 또는 bcrypt cost ≥ 12.
   - 전송: **TLS 1.3 + HSTS**.
5. **접속기록 보관·점검** — AccessLog **1년 보관**, 월 1회 이상 점검(이상 열람 탐지).
6. **보안프로그램 설치·갱신** — 서버 패치 정책, 의존성 취약점 스캔(CI), WAF.
7. **물리적 안전조치** — 사무실 출입통제, 운영자 PC 디스크 암호화·화면잠금·다운로드 차단(verification-sop §5-1).
8. **재해·재난 대비** — 자동 백업(일 1회) + 복구 절차 문서화, 분기 복구 훈련.

## 2-5. 제3자 제공 · 처리 위탁

| 대상 | 유형 | 동의 시점 | 동의 내용 |
|---|---|---|---|
| PortOne (결제) | 처리위탁 | 결제 시 | 결제대행 위탁 고지 |
| PASS/KCB (본인인증) | **제3자 제공** | 가입 본인인증 | 인증사 제공 동의 |
| **CODEF (재산 인증 동의자 한정)** | **제3자 제공 + 신용정보법 추가 동의** | 재산 트랙 B 선택 시 | **신용정보 조회 별도 명시 동의**(포괄 동의 불가) |
| AWS (호스팅) | 처리위탁 + **국외 이전** | 가입 약관 | 국외 이전 동의(국가·항목·목적·기간) |
| Resend (메일) | 처리위탁 + 국외 이전 | 가입 약관 | 동상 |
| PostHog / Sentry (분석·에러) | 처리위탁 + 국외 이전 | 가입 약관 | 동상, 가급적 가명·최소수집 |

- **국외 이전 고지 4요소**: 이전받는 자, 이전 국가·일시·방법, 이전 항목, 보유·이용 기간.

> **결정 필요 ⓖ** PostHog/Sentry 리전(US vs EU) 및 국외이전 동의 방식. 가능하면 **개인 식별 최소화(가명)** 로 위험 축소.

## 2-7. 침해사고 대응 절차

1. **인지** — 모니터링/제보 접수, 사고 등급 분류.
2. **초동 조치** — 영향 시스템 격리, **증거 보전**(로그 스냅샷), 추가 유출 차단.
3. **신고** — 1천 명 이상 또는 민감/고유식별정보 유출 시 **인지 후 72시간 이내** 개인정보위·KISA 신고.
4. **정보주체 통지** — 지체 없이(원칙 72시간 내) 유출 항목·시점·대응·문의처 통지.
5. **사후** — 원인 분석, 재발방지 대책, 결과 보고.

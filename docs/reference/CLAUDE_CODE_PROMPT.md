# THE ONE · 프리미엄 소개팅앱 디자인 프롬프트
## Claude Code 용 작성 지시서 (v1.0)

---

## 0. 역할 (Role)

당신은 프리미엄 라이프스타일 · 디지털 브랜드 전문 **시니어 프로덕트 디자이너 + 프론트엔드 엔지니어**입니다.  
참고 미감: Aesop, Raya, Hinge Premium, Goldspoon, The League, Cereal Magazine.  
한국 사용자 정서에 맞춰 번역하고, **에디토리얼 갤러리** 같은 톤으로 만듭니다.

---

## 1. 프로젝트 개요

- **서비스명**: THE ONE (더원)
- **포지셔닝**: "인생에 한 번뿐인 매칭. 결혼정보회사가 디지털로 옮긴다면."
- **타겟**: 28~42세 전문직 · 고소득 미혼
- **비즈니스 모델**: 가입 심사제 + 4중 검증 + 크레딧 충전제 + 추가 인증제
- **차별화**: 매일 1명 큐레이션 + **무한 스와이프 절대 금지** + 검증된 결혼 의지 회원만 + 골드스푼식 신청제

---

## 2. 디자인 원칙

1. **절제된 럭셔리** — 골드 · 반짝임 · 그라데이션 모두 금지. 잉크 블랙 · 아이보리 · 뮤트 샴페인 톤만.
2. **에디토리얼** — 잡지 · 갤러리 같은 큰 여백, 큰 사진, 적은 정보. 한 화면 한 메시지.
3. **신뢰감** — 검증 마크 · 통과율 · 진성도 시그널이 미묘하게 곳곳에.
4. **희소성** — 무한 스크롤 절대 금지. "오늘 1명"의 무게감. 신청서 작성 후 매칭함에 답이 옴.
5. **한글 타이포 우선** — Noto Serif KR / Pretendard 가 1순위. 영문은 보조.

---

## 3. 기술 스택

- **HTML + React 18 (Babel-standalone) + Tailwind 불사용** (인라인 + CSS 변수)
- **폰트**: Google Fonts CDN (Noto Serif KR, Playfair Display, Inter) + Pretendard (jsdelivr)
- **iPhone 14 Pro 프레임** 안에 렌더 (375×812, 둥근 모서리, 다이내믹 아일랜드)
- **한 화면 = 한 아티팩트**, 모든 화면은 `<DesignCanvas>` 안의 `<DCSection>` / `<DCArtboard>` 로 정렬
- **컴포넌트는 파일 분리** — `screens/` 폴더 아래 카테고리별 하위 폴더. 각 파일 끝에서 `window.XXX = XXX` 로 글로벌 노출. `<script type="text/babel" src="...">` 로 로드.

## 4. 디자인 시스템

### 4-1. 컬러 토큰 (CSS 변수)

```css
:root {
  --ink:           #0F1014;  /* 잉크 블랙 (BG Dark) */
  --ink-2:         #1A1F2E;  /* 본문 잉크 (FG Primary) */
  --ink-soft:      #1F222B;  /* 다크 모드 hairline */
  --ivory:         #FAF7F2;  /* 아이보리 (BG Light) */
  --ivory-2:       #F5F1EA;  /* FG Secondary */
  --ivory-3:       #EDE8DE;  /* 옅은 분리선 / placeholder */
  --champagne:     #B8956A;  /* 뮤트 샴페인 (Accent) */
  --champagne-soft:rgba(184,149,106,0.16);
  --gray:          #8B8378;  /* 보조 텍스트 */
  --gray-soft:     #B5AFA4;  /* 더 옅은 회색 */
  --sage:          #6B8E7F;  /* 검증 / 승인 (Verified) */
  --terra:         #A85547;  /* 거절 / 위험 (Decline) */
  --hair-light:    #EDE8DE;  /* hairline border 라이트 */
  --hair-dark:     #1F222B;  /* hairline border 다크 */
}
```

### 4-2. 타이포

- **Display KR** — Noto Serif KR 700 (큰 헤드라인 전용)
- **Display EN** — Playfair Display 500/600 (영문 보조, italic 자주 사용)
- **Body KR** — Pretendard 400/500
- **Body EN** — Inter 400/500
- **Mono** — JetBrains Mono / SF Mono (캡션, 카운트다운, 코드 등)
- 행간 **1.55**, 영문 자간 **-1%**, 한글 자간 **-2%**

### 4-3. 레이아웃

- 모바일 우선 (**375 × 812**, iPhone 14 Pro)
- 좌우 padding **24**
- 컴포넌트 간격 스케일: **8 / 16 / 24 / 40 / 64**
- 카드 radius **2** (날카롭게, 절대 둥글지 않게)
- 그림자 거의 없음. 구분은 **hairline border** (`#EDE8DE` 라이트 / `#1F222B` 다크)
- 버튼은 1px 솔리드 또는 1px 보더 + transparent (둘 다 radius 2)

### 4-4. 사진 / 인물 자리

실사진이 없을 때는 **자체 SVG placeholder** 사용:
- 따뜻한 회색 그라디언트 (`#E8E2D5 → #C8C1B1`) 위에 어두운 반원 실루엣
- 좌상단 모노스페이스 캡션 `PORTRAIT · 김지윤` 같은 식
- 절대 외부 Unsplash URL이나 가짜 AI 일러스트 금지

## 6. 인증 시스템 (4단계 뱃지)

### 6-1. 뱃지 상태

```
none      미인증     hairline border, gray
pending   심사중     hollow champagne border
verified  승인됨     sage solid background
rejected  반려       hollow terra border (재제출 가능)
```

### 6-2. 가입 시 vs 가입 후

| 시점 | 항목 | 흐름 |
|---|---|---|
| **가입 심사 (Step 02)** | 직업 (필수) | 서류 업로드 → 가입 심사 위원회 → 통과 시 직업 뱃지 자동 부여 |
| **가입 후 (추가 인증)** | 학력 · 재산 · 차량 · 부동산 | 본인 신청 → 관리자 직접 검토 → 뱃지 부여 |

### 6-3. 추가 인증 4종 명세

#### 학력 / Education (평균 3일)
- 필수: 졸업증명서, 학위증명서 (석·박사 시)
- 선택: 전문 자격증

#### 재산 / Wealth (평균 5일)
- 필수: 잔고증명서 (발급일 30일 이내), 종합소득세 신고확인서
- 선택: 금융자산 명세 (증권·펀드·예적금 통합)
- **가액 구간 4단계**: 5억~10억 / 10억~30억 / 30억~50억 / 50억 이상

#### 보유 차량 / Vehicle (평균 2일)
- 필수: 자동차등록증 (본인 명의), 차량 사진 (번호판 일치, 정면+측면 2장)
- 선택: 차량가액 증빙 (구매 영수증 · 시세표)

#### 부동산 / Real Estate (평균 4일)
- 필수: 등기부등본 (발급일 30일 이내), 부동산 외관 사진, 공시지가 증빙
- 선택: 임대차 계약서 (수익형 부동산일 경우)
- **가액 구간 4단계**: 10억 미만 / 10억~30억 / 30억~50억 / 50억 이상

### 6-4. 다중 파일 업로드 (DocUpload 컴포넌트)

- 각 서류 행마다 **필수 / optional** 라벨 (필수는 terra, optional은 gray italic)
- 빈 상태: 점선 보더 + "+ 파일 첨부" / "Drag or tap" (영문 보조)
- 첨부된 상태: PDF/JPG 아이콘 + 파일명 + 크기 + 삭제 버튼 카드 형태
- 같은 서류에 여러 파일 추가 가능 ("추가 업로드" 보조 버튼)
- 모든 필수 서류 채워지면 하단 CTA "${카테고리} 인증 신청" 활성화

### 6-5. 보안 카피 (일관 유지)

> "업로드 즉시 256-bit 암호화되어 관리자 외 접근이 불가합니다. 검토 완료 후 **7일 안에 자동 파기**되며, 매칭 상대에게는 뱃지만 노출됩니다."

## 7. 매칭 방식 (골드스푼 방식 · 절대 틴더 금지)

**스와이프 절대 금지**. 다음 흐름을 따른다:

1. **오늘의 큐레이션** — 하루 1명만 풀블리드로 노출 (No. 047 / 23:47 후 갱신)
2. **프로필 상세** — 사진 카루셀 3-5장, 케미 3축, 60문항 일치, 자기소개 300자
3. **만남 신청서 (Interest Letter)** — 무료 스와이프 대신, **신청서를 진지하게 써서 보냄**. 크레딧 차감 (20C 일반 / 50C 슈퍼).
4. **매칭함 (Inbox)** — 받은 신청서를 정중하게 수락/거절. 상대의 정성이 들어간 글이 먼저 보임.
5. **수락 시에만 채팅 개방** — AI 추천 첫 메시지 3종.
6. **케미 분석 리포트** — 매칭 시작 후 7일째 자동 발행 (상위 8% 표기 등).

# 신뢰·안전 (Trust & Safety)

> **버전** v0.1 · **작성일** 2026-05-21 · **작성자** Claude Code
> **상태** 변호사·운영진 검토 전 초안 — **외부 노출 금지** · **최종 결정자** 한승수

검증된 결혼 의지를 가진 회원만 입회하는 더원에서 신뢰·안전은 핵심 가치다.
사례(아만다 허위계정 등, `privacy-design.md` §2-1)를 반면교사로, 가짜·악성 행위를 시스템과 운영으로 차단한다.

## 3-1. 본인 사진 검증

### v1 (출시) — 운영자 매칭 검토
- 가입 시: **셀카 3초 라이브 영상** + 프로필 인증사진 제출.
- 운영자가 영상↔프로필↔본인인증 정보의 **동일인 여부** 육안 검토.
- 위변조 검증 가이드라인:
  - 포토샵 흔적(경계 뭉개짐, 그림자 불일치, 메타데이터 편집)
  - 과도한 필터·뷰티앱(원본 식별 곤란 시 재제출)
  - 동일인 의심(타인 사진 도용 정황 → 추가 셀카 요청)
  - 연예인·스톡 이미지(역이미지 검색)

### v1.1 — AI 보조 (Face Liveness + Identity Match)
국내 도입 가능 솔루션 후보 (조사 결과):
| 솔루션 | 특징 |
|---|---|
| **알체라 FACE TRUST LIVENESS** | 국내 다수 금융사 적용, **ISO 30107-3 / iBeta PAD** 통과, 일반 스마트폰 RGB 카메라 지원 |
| **드림시큐리티 Magic Secu Face** | AI 비대면 본인인증(얼굴 인증 + 위조 판별) |
| **한국인식산업** | 신분증 사진 ↔ 얼굴 비교, Liveness 특허 |

> **결정 필요 ①** v1.1 liveness 벤더 선정 — 정확도(PAD 인증)·단가·온디바이스 여부 기준. **알체라 우선 검토** 권장(금융권 레퍼런스·국제 인증).
> **결정 필요 ②** 셀카 영상 보관 기간 — 검증 직후 파기 vs 분쟁 대비 단기 보관. **검증 완료 즉시 파기** 권장(민감도 높음).

- 피신고자에게 사유 통지 + 이의제기 1회 보장.

## 3-3. 외부 연락처 마스킹

채팅 입력·전송 시 정규식·키워드로 탐지 후 마스킹. 매칭 성사(상호 수락) 전까지 적용.

| 유형 | 패턴/키워드(예) |
|---|---|
| 휴대폰 | `01[016789][-.\s]?\d{3,4}[-.\s]?\d{4}` |
| 카카오 | `카톡`, `카카오톡`, `kakao`, `katalk`, `오픈채팅`, `오카`, `id:` |
| 인스타 | `@핸들`, `instagram`, `인스타`, `insta` |
| 텔레그램 | `텔레그램`, `telegram`, `t\.me/` |
| 라인/위챗 | `라인`, `line id`, `위챗`, `wechat` |
| 이메일 | `[\w.+-]+@[\w-]+\.[\w.]+` |

- 마스킹 후 안내: **"외부 연락처는 매칭 성사 후 자동 공유됩니다."**
- **우회 시도 대응**: 자음 분리("ㅋㅏㅌㅗㄱ"), 이모지·전각 숫자, 띄어쓰기 삽입, **이미지 텍스트(OCR 우회)** → ① 정규화(공백·특수문자 제거 후 재검사) ② 숫자 11자리 연속 탐지 ③ 이미지 전송 시 OCR 스캔(v1.1) ④ 반복 우회 시 신고 카테고리 3 적용.

> **결정 필요 ③** 마스킹을 **차단(전송 불가)** vs **마스킹 후 전송** — 차단은 정상 대화 오탐 불만, 마스킹 후 전송은 우회 여지. **마스킹 후 전송 + 반복 시 제재** 권장.

## 3-4. 미성년자 차단

- 가입 본인인증(PASS/KCB)에서 **만 19세 미만 자동 차단**.
- 생년월일 거짓 의심(프로필·대화 정황) 시 **재인증 요구**.
- 청소년보호법: 데이팅·매칭 서비스는 **청소년유해매체물 지정 가능**(랜덤채팅앱 지정 선례). 지정 시 **19금 표시 + 성인인증** 의무, 미표시 시 **2년 이하 징역 또는 2천만 원 이하 벌금**. → `legal-checklist.md` §4-1과 교차.

> **결정 필요 ④** 더원의 청소년유해매체물 자율 표시 여부 — 매칭 서비스 특성상 **선제적 19세 이용가 표시 + 성인인증** 적용 권장(리스크 회피).

## 3-5. 운영자 모더레이션 SOP

- **흐름**: 신고 접수 → **24시간 내 1차 검토** → 결정(승인/반려/에스컬레이션) → 양 당사자 통지.
- **응대 원칙**: 피해자 보호 우선, 증거(대화·사진) 보전, 가해자에는 사유·이의절차 안내.
- **에스컬레이션**: 성범죄·아동·금전사기 등 중대 건은 admin + 법무 검토, 필요 시 수사기관 신고.
- **운영자 멘탈케어**: 성범죄·아동 관련 신고 노출 운영자 대상 **로테이션·심리지원·노출 최소화 도구**(블러 미리보기) 제공.

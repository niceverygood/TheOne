## P0 — 출시 직결 / 핵심 루프 완성

### 1. 큐레이션 사유 카드 (Why this match)
- 목적: 하루 1명의 설득력. 근거 없는 큐레이션은 랜덤처럼 느껴짐.
- 동작: `curation.tsx`에서 `matching.ts` 룰베이스 점수의 근거를 **문장형 공통점 3개**로 노출.
  예: "검증된 학력대 일치 · 같은 직업군(전문직) · 생활권 근접".
  점수 숫자 노출 금지(좋아요 카운터 금기 연관).
- KPI: 큐레이션 → 신청 전환율.

### 2. 만남 신청서 작성 가이드 (Letter Composer)
- 목적: 신청서(20C)가 "안녕하세요"로 낭비되면 전환·매너 모두 손해.
- 동작: `letter.tsx`에 유도 프롬프트 3종(가치관 1줄 · 프로필에서 끌린 점 · 만남 제안) + 글자수 가이드.
  슈퍼 신청(50C)은 상단 노출 + 우선 알림.
- KPI: 신청 수락률.

### 3. 인증 뱃지 월 (Verification Wall)
- 목적: 검증제가 본질인데 눈에 안 보이면 의미 없음. 추가 인증 수익화 유입.
- 동작: `profile.tsx`에 학력·재산·차량·부동산·직업·소득 뱃지 그리드(sage #6B8E7F).
  상대에겐 뱃지만 노출(서류 비공개, privacy-design.md). 미인증 항목 → `verify/` CTA.
- KPI: 추가 인증 시작률.

### 4. 채팅 외부연락처 자동 마스킹
- 목적: `masking.ts` 자산을 채팅에 연결. 외부 이탈·안전 리스크 차단(trust-safety.md).
- 동작: `chat.tsx` 전송 시 카톡ID·전화번호·인스타 패턴 자동 마스킹 + 신고/차단 진입점.
- KPI: 외부연락처 시도율, 신고 처리 SLA.

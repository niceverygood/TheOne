# 인증 운영 표준 절차 (Verification SOP)

> **버전** v0.1 · **작성일** 2026-05-21 · **작성자** Claude Code
> **상태** 변호사·운영진 검토 전 초안 — **외부 노출 금지** · **최종 결정자** 한승수
> **운영주체** 주식회사 바틀 (사업자 376-87-01076, 판교테크노밸리 스타트업캠퍼스 2동 8층)

더원의 인증 8종(학력·재산·차량·부동산 + 소득·직업·집안자산·명성, Phase 4 확장)은 단일 데이팅앱 중 가장 민감한 정보 묶음이다.
본 문서는 각 인증의 수집·검증·SLA·권한·반려·**보상** 절차의 진실의 원천이며, 코드(`packages/db`, `packages/shared`, `apps/admin`)는 이 문서를 따른다.

## 0. 공통 원칙

- 모든 서류는 **S3 + KMS 암호화** 저장, 검토 완료 **30일 후 자동 파기** (사본 일체 금지). 상세는 `privacy-design.md`.
- 매칭 상대에게는 **인증 뱃지만** 노출. 원본 서류·구체 수치는 절대 비노출.
- 인증 유효기간 **1년**. 만료 30일 전·7일 전 알림톡.
- 모든 인증 SLA: **검토 시작 24시간 이내 / 검토 완료 24시간 이내** (영업일 기준, 가입 심사 직업 검증은 평균 5일 별도).
- 본인인증(PASS/KCB) 정보(이름·생년월일·CI/DI)와 서류 기재사항이 **일치해야** 승인.

> **결정 필요 ①** SLA 24h를 영업일 기준으로 할지 24시간 실시간으로 할지. 운영 인력 1~2인 기준 영업일 권장.

## 2. 재산 인증 (Wealth) — 핵심 결정 다수

두 트랙 운영:

| 트랙 | 수집 | 발급처 | 유효기간 | 검증 |
|---|---|---|---|---|
| A. 잔고증명 | 잔고증명서 PDF | 은행 직발급 | 발급 7일 이내 | 운영자 육안 + 발급번호 |
| B. CODEF 자산조회 | 본인 동의 후 실시간 조회 | CODEF(보비 재사용) | 조회 시점 | 자동(API 응답) |

**가액 구간 뱃지** (구체 금액 비노출): 5억~10억 / 10억~30억 / 30억~50억 / 50억 이상.

> **결정 필요 ④ (최우선)** 최소 자산 기준.
> - 통과율 23% 목표 가정 시, 28~42세 전문직 타겟의 순금융자산 분포를 고려하면 **금융자산 5억** 또는 **총자산(부동산 포함) 10억**이 현실적 하한선.
> - 옵션: (a) 금융자산 단독 3억 (b) 금융자산 5억 (c) 부동산·차량 합산 총자산 10억. → **(c) 합산 10억 + 금융자산 최소 1억** 권장(자산가 포착 + 현금흐름 확인).

> **결정 필요 ⑤** 부동산·차량과 **합산 인정** 여부 → 합산 인정하되 인증별 뱃지는 분리 표기(재산=금융, 부동산=별도) 권장.
> **결정 필요 ⑥** CODEF 사용 시 **신용정보법·개인정보보호법 추가 동의** → `privacy-design.md` §2-5와 교차. 신용정보 조회는 **별도 명시 동의** 필수(포괄 동의 불가).
> **결정 필요 ⑦** 영문 증명서/해외 자산 → v1 **국내 금융기관 발급분만**. 해외 자산 보류.

**트랙 A 검토 체크포인트**: 발급은행·계좌주 성명·발급일·잔액 판독, 7일 이내, 본인 성명 일치, 위변조 흔적(폰트·정렬).

## 4-E. 인증 승인 보상 (인앱화폐) — Phase 4 신규

## 5. 공통 운영 규칙

### 5-1. 운영자 권한 3단계 (Phase 3 `apps/admin`)
| 권한 | 범위 |
|---|---|
| **viewer** | 신청 메타데이터만 열람(서류 원본 불가). 통계·대기열 확인 |
| **reviewer** | 문서 원본 열람·승인·반려·반려사유 입력 |
| **admin** | 정책·운영자 계정·권한 관리, 강제 파기 |

- 모든 문서 열람 시 **AccessLog 자동 기록**: `operator_id, document_id, action, at, ip`.
- 운영자 PC 통제: 문서 뷰어 **다운로드 차단·우클릭 차단**, **워터마크(운영자 ID + 열람 시각)** 강제. 접근은 IP 화이트리스트 + MFA.

### 5-2. 반려 사유 표준 문구 10종
1. 해상도 부족 — 글자 판독 불가, 선명한 재촬영 필요
2. 발급 7일 초과 — 최근 7일 이내 발급분 재제출 필요
3. 본인 명의 불일치 — 서류 명의가 본인인증 정보와 다름
4. 위조 의심 — 편집·합성 흔적, 원본 재제출 필요
5. 정보 일부 가려짐 — 필수 기재란이 가려짐, 전체 보이게 재촬영
6. 만료된 서류 — 유효기간 경과 문서
7. 발급처 부적격 — 정부24/은행/등기소 등 지정 발급처 아님
8. 본인인증 정보와 상이 — 성명·생년월일 등 불일치
9. 기재사항 불일치 — 신청 입력값과 서류 내용 상이
10. 기타 — 상세 사유 직접 기재(자유 입력)

- 반려는 알림톡으로 사유 + 재제출 안내. **재제출 무제한**(단 24h 내 반복 반려 3회 시 운영자 에스컬레이션).

### 5-3. 갱신
- 유효기간 1년. 만료 **30일 전·7일 전** 알림톡. 만료 시 뱃지 자동 비활성 → 매칭 노출에서 '미인증' 처리.

## 2. 앱 설명 (App Description)

**한 줄 소개**: 검증된 사람만 만나는 인증 기반 매칭. 가입 통과율 23%.

**전체 설명 (초안)**
> THE ONE은 결혼을 진지하게 생각하는 분들을 위한 인증 기반 매칭 서비스입니다.
>
> · 가입 심사제 — 무한 스와이프 없이, 심사를 통과한 분들만 입회합니다.
> · 4종 인증 — 학력·재산·차량·부동산을 운영자가 직접 검토해 뱃지를 부여합니다.
> · 매일 1명 큐레이션 — 가치관 60문항 기반으로 매일 한 분을 정성껏 추천합니다.
> · 진심을 담은 만남 신청 — 가벼운 호감 대신, 신청서를 써서 마음을 전합니다.
>
> 제출하신 인증 서류는 암호화 보관되며 검토 후 자동 파기됩니다. 매칭 상대에게는 뱃지만 표시됩니다.

> ※ 본 서비스는 만 19세 이상만 이용할 수 있습니다.

**키워드(App Store, 100자)**: 소개팅,결혼,매칭,인증,전문직,데이팅,프로필,진지한만남,결혼정보,더원

## 3. 스크린샷 5장 (캡션)
1. **THE ONE / 통과율 23%** — 잉크블랙 스플래시 (브랜드 인상)
2. **인증 4종** — 학력·재산·차량·부동산 뱃지 (차별점)
3. **오늘의 큐레이션** — 매일 1명 풀블리드 (핵심 경험)
4. **만남 신청서** — 진심을 담은 글쓰기 (골드스푼식)
5. **케미 리포트** — 가치관 일치 분석 (신뢰감)

> 디자인 원천: `docs/reference/theone-standalone.html`. 캡션은 잉크블랙 배경 + Noto Serif KR. 골드/하트 금지.

## 4. 미리보기 영상 (15~30초 시나리오)
스플래시(통과율 23%) → 인증 4종 뱃지 → 오늘의 큐레이션 → 신청서 작성 → 매칭 수락 → 케미 리포트. BGM 차분, 자막 최소.

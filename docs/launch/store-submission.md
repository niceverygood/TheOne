## B. 심사용 리뷰어 안내 (테스트 계정)

> Apple: **App Store Connect → 앱 정보 → 앱 심사 정보 → 메모(Notes)** 에 붙여넣기
> Google: **Play Console → 앱 콘텐츠 → 앱 액세스 권한 → "모든 기능이 제한 없이 제공됨" 아님 → 안내 추가** 에 붙여넣기

```
[리뷰어 안내]
- 본 앱은 가입 심사 기반 매칭 서비스입니다. 정식 PASS/KCB 본인인증 연동 전이라,
  심사 편의를 위해 가입 단계가 데모(mock) 인증으로 동작합니다.
- 가입 방법:
  1) 시작 화면 → "가입 신청"
  2) 휴대폰 번호: 아무 번호나 입력 (예: 010-1234-5678)
  3) 인증번호: 6자리 아무 숫자나 입력 (예: 482000) → 통과
  4) 이후 프로필/설문 단계를 따라 진행하면 메인(오늘의 큐레이션)에 진입합니다.
- 전체 화면 둘러보기: 시작 화면 하단 "전체 화면 둘러보기"를 누르면 가입 없이
  모든 화면(큐레이션·신청서·매칭·채팅·인증·결제·안전)을 확인할 수 있습니다.
- 계정 삭제 경로(Apple 5.1.1(v) / Google 요구사항):
  메뉴 → "안전 / 졸업" → "계정 영구 삭제", 또는 프라이버시 화면 하단 "계정 영구 삭제".
  삭제 항목 고지 + 동의 체크 후 즉시 요청 처리됩니다.
- 결제: 크레딧 충전은 Apple/Google 인앱결제(IAP)로만 이루어지며, 외부 결제 유도는 없습니다.
- 본 서비스는 만 19세 이상만 이용 가능하며, 정식 출시 시 본인인증으로 연령을 차단합니다.
```

### 자세한 설명 (최대 4000자)
```
THE ONE은 결혼을 진지하게 생각하는 분들을 위한 인증 기반 매칭 서비스입니다.

· 가입 심사제 — 무한 스와이프 없이, 심사를 통과한 분들만 입회합니다.
· 4종 인증 — 학력·재산·차량·부동산을 운영자가 직접 검토해 뱃지를 부여합니다.
· 매일 1명 큐레이션 — 가치관 기반으로 매일 한 분을 정성껏 추천합니다.
· 진심을 담은 만남 신청 — 가벼운 호감 대신, 신청서를 써서 마음을 전합니다.

제출하신 인증 서류는 암호화 보관되며 검토 후 자동 파기됩니다. 매칭 상대에게는 인증 뱃지만 표시됩니다.

신고·차단 기능과 운영 모니터링으로 안전한 만남 환경을 유지합니다.

※ 본 서비스는 만 19세 이상만 이용할 수 있습니다.
```

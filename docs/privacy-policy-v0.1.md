# THE ONE 개인정보처리방침 (초안)

> **버전** v0.1 · **작성일** 2026-05-21 · **작성자** Claude Code
> **상태** ⚠️ **변호사 검토 전 초안 — 실제 게시·적용 금지**. v1.0(검토 완료) 태깅 후 사용.
> 근거 설계: `docs/privacy-design.md`

주식회사 바틀(이하 "회사")은 THE ONE(이하 "서비스") 이용자의 개인정보를 중요하게 생각하며,
「개인정보 보호법」 등 관계 법령을 준수합니다. 본 방침은 법정 필수 기재사항을 포함합니다.

---

### 1. 수집하는 개인정보 항목 및 방법
- 필수: 휴대폰번호, 이름, 생년월일, 성별, 이메일, CI/DI(본인인증), 직업 카테고리·직장명, 학력, 거주지역, 프로필 사진
- 선택: 자기소개
- 추가 인증(별도 동의): 학력·재산·차량·부동산 인증 서류
- 자동 수집: 접속 로그, IP(해시), 기기정보, 쿠키
- 방법: 본인인증사 연계, 이용자 직접 입력, 서비스 이용 중 자동 생성

### 2. 개인정보의 수집·이용 목적
회원 식별·가입 심사, 인증 뱃지 부여, 매칭 서비스 제공, 결제·정산, 고지·통지, 부정이용 방지, 법령 의무 이행.

### 3. 보유 및 이용 기간
- 회원정보: 탈퇴 후 [30일] 보관 후 파기 *(결정 필요)*
- 인증 서류: 검토 완료 후 **30일 자동 파기**
- 결제·거래 기록: **5년**(전자상거래법)
- 접속기록: **1년**
- 매칭·대화: 매칭 종료 후 [6개월] *(결정 필요)*

### 4. 개인정보의 파기 절차 및 방법
보유기간 경과·목적 달성 시 지체 없이 파기. 전자파일은 복구 불가능한 방식으로 삭제, 출력물은 분쇄·소각. 자동 파기 배치 일 1회 실행.

### 5. 제3자 제공
법령 또는 정보주체 동의가 있는 경우에 한함. 본인인증사(PASS/KCB), CODEF(재산 인증 동의자에 한함, 신용정보 조회 별도 동의).

### 6. 처리위탁 및 국외 이전
- 위탁: PortOne(결제), Resend(이메일), PostHog·Sentry(분석·오류), AWS(호스팅)
- 국외 이전 고지: 이전받는 자 / 국가·일시·방법 / 항목 / 보유·이용 기간 *(별표로 명시 예정)*

### 7. 정보주체의 권리·행사 방법
열람·정정·삭제·처리정지 요구 가능. 서비스 내 설정 또는 개인정보 보호책임자에게 요청.

### 8. 개인정보의 안전성 확보조치
내부관리계획, 접근권한 관리·접근통제(MFA·IP화이트리스트), 암호화(전송 TLS1.3·저장 AES-256·KMS), 접속기록 1년 보관·점검, 보안프로그램, 물리적 통제. (상세 `privacy-design.md` §2-4)

### 9. 만 14세(및 19세) 미만 처리
서비스는 **만 19세 이상**만 가입 가능. 본인인증으로 연령 확인하며 미성년자 가입을 차단합니다.

### 10. 쿠키 등 자동수집 장치
서비스 개선·분석 목적 쿠키 사용. 브라우저 설정으로 거부 가능.

### 11. 개인정보 보호책임자(CPO)
- 성명/직책: *(지정 필요)* · 연락처: privacy@the-one.kr

### 13. 영상정보처리기기 운영
해당 없음.
